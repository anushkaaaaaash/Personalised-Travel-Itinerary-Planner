4. Configure an existing public publishable/anon key locally for authentication. Never use service credentials for user CRUD or expose them in the frontend. Keep local mode and legacy ownership disabled unless separately reviewed.
5. Account creation, credential changes, live synthetic writes and permanent deletion each need their own authorization. Delete is permanent; confirm exact records before cleanup. Never assign unknown legacy records to a new user.
